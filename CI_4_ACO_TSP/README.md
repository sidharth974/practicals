# CI-4: Ant Colony Optimization for TSP

**Aim:** Apply ACO to the Travelling Salesman Problem to find a short tour through every city.

**Tech:** Python + NumPy.

## Run
```bash
pip install numpy
python aco_tsp.py
```

## Demo
A 4-city symmetric distance matrix, 10 ants, 50 iterations, evaporation 0.9 (i.e., 10% decay per iteration), α=1, β=2.
