# Experiment 8: Distributed Evolutionary Algorithm

**Aim:** Implement a simple evolutionary algorithm (DEAP-style) — selection, mutation, and population update across generations — to evolve toward an optimal solution.

**Tech:** Plain Python (uses only the standard library `random` module). The same idea can be expressed using the DEAP framework if needed.

## Requirements
- Python 3.6+
- Optional: install DEAP if you wish to extend the program with the framework
  ```bash
  pip install -r requirements.txt
  ```

## How to run
```bash
python deap_evolution.py
```

## Expected Output (varies due to randomness)
```
Best Solution: 0
```
