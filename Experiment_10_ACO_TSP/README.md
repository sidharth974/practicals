# Experiment 10: Ant Colony Optimization for TSP

**Aim:** Apply Ant Colony Optimization (ACO) to find the shortest route that visits every city exactly once in the Traveling Salesman Problem.

**Tech:** Plain Python (uses only the standard library `random` module).

## Requirements
- Python 3.6+

## How to run
```bash
python aco_tsp.py
```

## Expected Output (varies due to randomness)
```
Best Path: [0, 1, 4, 2, 3]
Shortest Distance: 15
```
