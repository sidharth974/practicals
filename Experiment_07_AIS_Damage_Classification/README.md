# Experiment 7: AIS Pattern Recognition for Structural Damage Classification

**Aim:** Apply Artificial Immune System (AIS) pattern recognition to classify structural data as damaged or undamaged by matching antigens (data) to the closest antibody (detector).

**Tech:** Plain Python (uses only the standard library `random` module).

## Requirements
- Python 3.6+

## How to run
```bash
python ais_damage.py
```

## Expected Output (antibody values vary per run)
```
Antigen: 0 Matched Antibody: 0.0421...
Antigen: 0 Matched Antibody: 0.0421...
Antigen: 1 Matched Antibody: 0.8973...
...
Classification Completed
```
