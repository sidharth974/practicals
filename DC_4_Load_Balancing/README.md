# DC-4: Load Balancing Simulation

**Aim:** Simulate a load balancer distributing client requests across multiple backend servers using Round Robin, Least Connections, and Random algorithms.

**Tech:** Plain Python (object-oriented: Server / Request / LoadBalancer classes).

## Run
```bash
python load_balancing.py
```

## What you'll see
Three sections, one per algorithm, each showing how 10 requests are routed across 3 servers, plus the final load distribution.
