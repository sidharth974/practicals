# Experiment 4: Fuzzy Set Operations

**Aim:** Implement Union, Intersection, Complement and Difference on fuzzy sets (membership values in [0,1]).

**Tech:** Plain Python (no external libraries).

## Requirements
- Python 3.6+

## How to run
```bash
python fuzzy_sets.py
```

## Expected Output
```
Set A      : [0.2, 0.5, 0.7, 0.9]
Set B      : [0.3, 0.6, 0.4, 0.8]
Union      : [0.3, 0.6, 0.7, 0.9]
Intersection: [0.2, 0.5, 0.4, 0.8]
Complement of A: [0.8, 0.5, 0.30000000000000004, 0.09999999999999998]
Difference (A-B): [0.2, 0.4, 0.6, 0.19999999999999996]
```
