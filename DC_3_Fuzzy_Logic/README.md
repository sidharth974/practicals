# DC-3: Fuzzy Set Operations and Composition

**Aim:** Implement fuzzy set Union, Intersection, Complement, Difference, plus Cartesian product of two fuzzy sets to form a fuzzy relation, and Max-Min composition of two fuzzy relations.

**Tech:** Plain Python (sets represented as `dict`).

## Run
```bash
python fuzzy_logic.py
```

## What the script demonstrates
- All four standard set operations on sample sets `A` and `B`.
- Cartesian product `A × B` and `B × C` to build two fuzzy relations.
- Max-Min composition `R o S` of those two relations.
